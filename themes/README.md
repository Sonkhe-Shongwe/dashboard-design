# Power BI theme starters

| Theme | Use |
|---|---|
| [Portfolio Light](portfolio-light.json) | Neutral canvas, ink text, blue and teal data series. Suits comparison reports and detailed tables. |
| [Endurance Dark](endurance-dark.json) | Charcoal canvas, light text and a yellow primary data accent. Suits an editorial or monitoring dashboard. |

In Power BI Desktop, open the report theme menu and choose **Browse for themes**, then select a JSON file. These themes set core colour defaults. Apply the image, page layout, spacing, chart scales, series mappings, navigation and conditional formatting in the report. Treat `good`, `neutral` and `bad` as palette roles and choose the actual meaning for each metric. For example, a negative lap-time variance means the selected lap is faster.

The JSON files were parsed and checked against the documented theme properties. Power BI Desktop import and the appearance of individual visuals are pending. [Microsoft custom report theme documentation](https://learn.microsoft.com/en-us/power-bi/create-reports/report-themes-create-custom)
