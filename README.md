# Dashboard Design

A design handbook and reference gallery for building dashboards with clear analytical hierarchy and a distinct visual identity. The collection covers Power BI reports, browser prototypes, and the design decisions that transfer between them.

## Start here

| I want to… | Open |
|---|---|

## Design studies

| Study | What it demonstrates | Evidence |
|---|---|---|
| [Endurance Race Telemetry](examples/endurance-telemetry/README.md) | Editorial imagery, a dark product theme, icon-led KPIs, overlaid speed traces and sector deltas | Browser prototype with three simulated lap selections |
| [Credit Portfolio](examples/credit-portfolio/README.md) | A light finance theme, ratio context, matched axes, persistent filters and annual reconciliation | Browser prototype using published cohort aggregates, with a link to the report design specification |

Clone or pull this repository and open the HTML file listed in each study in a browser. The [theme starter files](themes/README.md) are available for Power BI Desktop.
