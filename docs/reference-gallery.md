# Dashboard reference gallery

Research snapshot: 13 November 2026. The design observations below describe the elements worth studying in each reference. Follow the source for the original work and its download or preview terms.

## Product-like and award-recognised dashboards

| Reference | What to inspect | What to borrow |
|---|---|---|
| [Power BI Basketball Cards · Injae Park](https://community.fabric.microsoft.com/discussions/pbi_contestsgallery/winner-of-week-3--power-bi-basketball-cards/4600448) · [LinkedIn walkthrough](https://www.linkedin.com/posts/injae-park_powerbi-dashboarddesign-sportsanalytics-activity-7345811931527589888-DF7M) | A Power BI DataViz World Championships weekly winner. Player portraits and team marks identify entities. A card flip reveals stats. A court image supplies spatial context for the scatter plot. | Tie the signature interaction to the subject. Keep charts and stats responsive to selection. |
| [Luminate Performance Management Dashboards · Good Design](https://www.chi-athenaeum.org/interactive-media-2025/2025/12/16/luminate-performance-management-dashboards-2025/) · [Mariska van Kan’s LinkedIn post](https://www.linkedin.com/posts/mariska-van-kan_powerbi-dashboard-uxdesign-activity-7414209810767818752-7In8) | Role-specific report designs for legal professionals, refined through workshops and user acceptance testing. The award gallery includes multiple screens. | Give each audience a view built around its decisions. Judge the design using realistic tasks and user feedback. |
| [Formula 1: Drivers and Grand Prix Insights · Microsoft Fabric Community](https://community.fabric.microsoft.com/t5/Data-Stories-Gallery/Formula-1-Drivers-and-Grand-Prix-insights/td-p/3679073) | A motorsport-themed report and public gallery entry. | Study how the subject can influence the visual identity and report sections. |
| [Rafael Nadal’s Career in Numbers · Aanor](https://community.fabric.microsoft.com/discussions/pbi_contestsgallery/week-3---tennis---rafael-nadals-career-in-numbers/4597658) · [Judges’ notes](https://community.fabric.microsoft.com/blog/community_blog/%F0%9F%8F%86-power-bi-dataviz-world-championships--week-3-winner-%F0%9F%8E%89/4606956) | The weekly runner-up used tennis-ball symbols in a matrix. | Use a domain-specific shape where it gives a repeated encoding a clear identity. Pair the symbol with a label or legend. |

## Finance and analytical reporting

| Reference | Access and technique |
|---|---|
| [Numerro Finance templates](https://www.numerro.io/use-cases/power-bi-finance-template) | Public light, dark, mobile and print previews. Study consistent spacing, panels and chart typography across screens. |
| [Briqlab Banking Loan Portfolio](https://www.briqlab.io/power-bi/templates/banking-loan-portfolio-power-bi-dashboard) | Public previews. The advertised PBIX download requires sign-in. Study compact lending KPIs and filtering. |
| [ZoomCharts Credit Risk Analysis](https://zoomcharts.com/en/microsoft-power-bi-custom-visuals/dashboard-and-report-examples/view/credit-risk-analysis-dashboard) | Public gallery preview with an account-gated PBIX. Study the path from portfolio overview to a narrower segment. |
| [Nova Bank Credit Risk Analytics · Gus Bavia](https://datadna.onyxdata.co.uk/portfolios/nova-bank-credit-risk-analytics-dashboard/) | Public challenge entry. Study how a larger lending report separates related questions across pages. |
| [Bank Loan Portfolio Analysis · Omar Rezk](https://omarrez2.github.io/projects/bank-loan-analysis) | Public case study and repository link. Study how the report image, decision brief and evidence work together in a portfolio. |
| [CFPB · Mortgages 90 or More Days Delinquent](https://www.consumerfinance.gov/data-research/mortgage-performance-trends/mortgages-90-or-more-days-delinquent/) | Public interactive report. Study visible population, delinquency threshold, time basis and source attribution. |
| [Microsoft Corporate Spend sample](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-corporate-spend) | Downloadable PBIX for inspecting native report composition and interaction in Desktop. |
