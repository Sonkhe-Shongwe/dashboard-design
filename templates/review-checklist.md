# Dashboard review checklist

- **Dashboard and revision**
- **Reviewer and date**
- **Environment and viewport**

## Visual design

- [ ] The audience, subject and current scope are evident on the opening screen.
- [ ] One primary number or chart leads the reading order and related evidence sits close to it.
- [ ] Spacing, alignment, visual titles and number formats are consistent across pages.
- [ ] Icons and imagery contribute to navigation, identity or interpretation. Usage terms and credits are recorded where applicable.
- [ ] Normal text, large text and essential graphical elements meet the applicable contrast checks. Colour meaning has a visible second cue.
- [ ] Main labels, controls and required table rows fit on the intended viewing surface.

## Analytics and interactions

- [ ] KPI values, denominators, references and units match the underlying data in default and representative filtered states.
- [ ] Comparisons use an appropriate chart, consistent scale where required and clear sign or status semantics.
- [ ] Filters, page navigation, clearing and return states behave as documented.
- [ ] A user can complete the main investigation task using visible controls. Keyboard order, focus and accessible names are usable.
- [ ] Zero, missing data and empty states are distinguishable where possible.
